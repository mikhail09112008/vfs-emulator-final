# Эмулятор оболочки ОС с VFS (Вариант №21)

Программное решение практических заданий по дисциплине «Конфигурационное управление».
Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом (GUI) и виртуальной файловой системой (VFS) в памяти.

## Возможности

- **GUI-интерфейс** на базе `tkinter` (заголовок окна содержит имя VFS).
- **Парсер команд** с поддержкой кавычек (используется `shlex`).
- **Параметры командной строки**:
  - `--vfs <путь>` — загрузка VFS из CSV-файла в память.
  - `--script <путь>` — выполнение стартового скрипта при запуске.
- **Выполнение скриптов**: остановка при первой ошибке с имитацией ввода/вывода.
- **Отладочный вывод** параметров при запуске (в консоль).

## Реализованные команды

- `ls` — список файлов и папок.
- `cd` — переход по директориям (поддержка `..`, `.`, абсолютных и относительных путей).
- `cat` — вывод содержимого файла.
- `whoami` — имя текущего пользователя (`root`).
- `uname` — имя ОС (`VFS-Emulator`).
- `rmdir` — удаление *пустой* директории (с проверкой ошибок).
- `echo` — вывод аргументов.
- `exit` — выход из эмулятора.

## Формат VFS (CSV)

Виртуальная ФС хранится в CSV-файле и загружается в память (файл на диске не изменяется).
